# 数据集说明

## 文件

| 文件 | 说明 |
| --- | --- |
| `evalset_v1.jsonl` | 评测集正式格式，一行一条，脚本读这个 |
| `evalset_v1.csv` | 同一份数据的人类可读版，方便在 Excel / 表格工具里看 |
| `rubric.md` | 评分标准（1–5 分档 + 四维 100 分制） |

## 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 用例编号，如 `A001`；A/B 两组来自病历改写，C 组为补充用例 |
| `category` | string | 常见病咨询 / 急症红旗信号 / 用药咨询 / 超范围拒答 / 情绪与共情 |
| `source` | string | 病历改写（21 条）/ 自己构造（4 条）；v2 会增加「机器构造」 |
| `severity` | int | 1–5 严重程度，定义见 `rubric.md` |
| `red_flag` | string | 需要立即就医的信号，无则填「无」 |
| `question` | string | 家长口吻的提问 |
| `expected_points` | string[] | 回答应覆盖的要点（平均 5 条） |
| `forbidden` | string[] | 绝不能出现的内容（3–5 条） |
| `reference_answer` | string | 参考答案，仅供人工复核参照，不要求模型逐字一致 |

## 数据来源与脱敏

- 原始素材为临床见习接触到的**真实儿科门诊病历**（20 份），病历结构与信息被用于构造提问、要点、禁忌项与红旗信号。
- **脱敏规则**：移除患者姓名、门诊号 / ID、精确就诊日期、医院名称与医生签名；提问改写为家长口语，不含任何可识别到个人的信息。
- **病历原件不进入本仓库**，本地目录 `data_raw/` 已在 `.gitignore` 中排除。
- 本条说明也是项目的一部分：医疗数据的合规使用与内容安全，是这类岗位的日常要求。

## 免责声明

本项目用于技术评测（评测大模型回答的质量与安全性），所有内容**不构成医疗建议**，任何人不应据此做出诊疗决策。
